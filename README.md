# Minesweeper-Remake

A remake of the classic game of Minesweeper in C.

**CS2600 Final Project**\
Team: Vanessa Ramirez, Mario Chong Loo, Andre Lennox, Sydney Lopez, Yostina Seddik

## Repo Layout
```
Minesweeper-Remake/
   ├── Makefile
   ├── main.c        // game loop, menu
   ├── board.c/.h    // board creation, display, mine placement, counts
   ├── input.c/.h    // coordinate parsing and validation
   ├── game.c/.h     // reveal, flood-fill, flags, win/lose
   └── README.md

```
